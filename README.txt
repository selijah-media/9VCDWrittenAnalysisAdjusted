VCD Mug Packaging Analysis - upload to a NEW GitHub repository (GitHub Pages)

1. Sign in to GitHub > click + (top right) > New repository.
   Repository name: vcd-mug-analysis-2   (any name without spaces works)
   Set it to Public. Do not tick "Add a README". Click Create repository.
2. On the empty repository page choose "uploading an existing file".
3. Unzip this download. Open the unzipped folder and drag EVERYTHING inside it
   (index.html, item.html, sample.html, criteria.html and the css, js and images folders)
   into the GitHub upload box. Dragging whole folders keeps the structure. Click "Commit changes".
   If GitHub limits one upload, upload in batches: the 4 pages + css + js first,
   then images/items, images/slides and images/posters one folder at a time.
4. Go to Settings > Pages. Under "Build and deployment" choose Deploy from a branch,
   branch "main", folder "/ (root)", then Save.
5. After a minute your site is at https://YOUR-USERNAME.github.io/vcd-mug-analysis-2/

Adding more mugs later: put the JPEG in images/items/ and add its entry in js/data.js.
